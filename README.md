# أثر — مختبر تقنية المعلومات

منصة المعلم لمتابعة الطلاب والحوار والتقارير، بواجهة عربية وتخزين محمي في Supabase.

الرابط المستقل: https://ma1980jid.github.io/athar-it-lab/

## النشر

تنشر ملفات `site/` الثابتة على GitHub Pages. لا يحتاج تشغيلها إلى Node.js في المتصفح أو خادم مخصص. تعتمد صفحة الدخول على Supabase Auth، وتعزل سياسات RLS بيانات المعلم عن الزوار والحسابات الأخرى.

```text
npm ci
npx esbuild sdk-entry.js --bundle --format=iife --platform=browser --minify --target=es2022 --outfile=site/vendor/supabase.js
node check-cloud.cjs
```

إصدارات الاعتمادات مثبتة في package.json وpackage-lock.json. الملف المنشور `site/cloud-config.js` يحتوي مفتاح publishable فقط، وصلاحيته مقيدة بسياسات قاعدة البيانات. لا تضف مفتاح service_role أو نسخ المتابعة إلى المستودع.

## قاعدة البيانات

مشروع Supabase: `kkjhqvtbafvivnxpomrd`، باسم `athar-it-lab`، ضمن المنظمة التي اختارها المالك. بنية الجداول والسياسات في `supabase/schema.sql`، وقد طُبقت على المشروع الجديد.

- `athar_allowed_teachers`: قائمة المعلمين المخولين، قابلة للإدارة من قاعدة البيانات فقط.
- `athar_workspaces`: نسخة بيانات متابعة لكل مستخدم، مع رقم إصدار لمنع تعارض جهازين.
- `athar_import_package`: قوائم الطلاب والخطة الأصلية المحمية. لا يحتوي المستودع على قوائم الطلاب الحقيقية.

لا يوجد تسجيل دخول عام إلى بيانات الطلاب. الحساب المخول حاليًا هو البريد المدرسي للمالك. عند إضافة معلم آخر، أضف بريده عبر إدارة قاعدة البيانات؛ لا تمنح الكتابة على جدول الصلاحيات للمتصفح.

## أول استخدام ونقل المتابعة

1. اضبط Site URL وRedirect URLs في إعدادات Supabase Auth على رابط GitHub Pages النهائي.
2. افتح الموقع، واكتب البريد المدرسي وكلمة مرور جديدة من ١٢ محرفًا على الأقل، ثم اختر «أول استخدام؟ إنشاء حساب المعلم».
3. أكد البريد من الرسالة ثم سجّل الدخول. حساب Supabase Dashboard لا ينشئ حسابًا تلقائيًا داخل التطبيق.
4. من الموقع القديم، في المتصفح الذي سجلت فيه المتابعة، اضغط «نسخة احتياطية».
5. في الموقع الجديد اختر «استعادة نسخة» وحدد الملف. ستستبدل البيانات الحالية لذلك صدّر أي بيانات موجودة فيه أولًا.
6. انتظر عبارة «محفوظ في السحابة»، وراجع سجل طالب وتقريرًا ثم افتح الحساب على جهاز ثان للتحقق.

عند أول دخول تُحمّل قوائم الطلاب والخطة من Supabase تلقائيًا، مع إبقاء الشعبة الأولى فارغة. لا يتم ذلك إذا كانت لديك نسخة سحابية أو تغييرات محلية معلقة، ولا يُنشأ سجل متابعة أو درجات افتراضية. استعادة النسخة الاحتياطية مطلوبة لنقل سجل المتابعة السابق وإعدادات المعلم الدقيقة.

## الحفظ والتعارض

تُخزن نسخة محلية معلقة خاصة بمعرّف المستخدم حتى ينجح الحفظ السحابي. لا تعتبر عبارة الحفظ المحلي ضمانًا لوصول البيانات إلى السحابة؛ راقب مؤشر الحالة. عند انقطاع الشبكة استخدم «إعادة الحفظ» أو نزّل نسخة احتياطية.

إذا تغيرت النسخة السحابية من جهاز آخر، يتوقف الإرسال ويُتاح تصدير النسخة المحلية قبل فتح النسخة الأحدث. لا تُدمج التعديلات المتعارضة تلقائيًا. استخدم «تحديث من السحابة» عند الانتقال بين الأجهزة.

هذا المستودع لا يحتوي سجل المتابعة الموجود داخل متصفح الموقع القديم. لا تحذف الرابط القديم قبل التحقق من استعادة النسخة.
